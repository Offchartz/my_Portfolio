## ⚙️ ARCHITECTURE_OVERVIEW

This repository houses my interactive, cyberpunk-themed developer portfolio. Designed as a high-octane netrunner HUD, it operates as a live telemetry dashboard featuring a fully functional bash terminal emulator, CRT scanline aesthetics, and dynamic project matrices.

Built with zero heavy frameworks, it relies entirely on optimized, vanilla web technologies.

## ⚡ CORE_DIRECTIVES (FEATURES)

* **Cybernetic HUD Interface:** Dark slate and neon crimson colorway with animated CRT scanlines, background matrix grids, and glitch typography.
* **Interactive CLI Emulator:** Fully functional bash terminal. Visitors can execute commands like `whoami`, `projects`, `skills`, `philosophy`, and hidden easter eggs.
* **Operations Matrix:** Structured data cards for active builds including **MLMS** (Microfinance Loan Management) and **TMS** (Ticket Management System).
* **Zero Dependencies:** Pure semantic HTML5, modern CSS3, and Vanilla JavaScript. No compilation required.
